    Utilities¶

    The eptr2.util module provides utility functions for common operations.

    Time Utilities¶

    eptr2.util.time¶

    Utility functions for time and date handling.

    from eptr2.util.time import iso_to_contract

    iso_to_contract¶

    Converts ISO datetime to contract symbol format.

    from eptr2.util.time import iso_to_contract

contract = iso_to_contract("2024-07-29T10:00:00+03:00")
print(contract)  # e.g., "PH24072910"

    Cost Utilities¶

    eptr2.util.costs¶

    Imbalance and KÜPST (production plan deviation) prices and costs. Start with the two main functions: they resolve every regulation parameter (floor and ceiling prices, V, B, margins, KÜPST tolerance and multiplier by category) for each hour from its delivery date, so a range spanning regulation changes is priced hour by hour. EPİAŞ's published imbalance prices are used where available; they are calculated only for hours without them. Hours without SMP (such as the rest of the current day) are skipped with a warning.

    from eptr2.util.costs import calculate_imbalance_prices, calculate_imbalance_costs

## Hourly prices, unit costs and every parameter used (fetches mcp-smp-imb)
prices_df = calculate_imbalance_prices("2026-10-01", "2026-10-07", eptr=eptr)

## Imbalance and KÜPST costs of actual vs forecast rows
costs_df = calculate_imbalance_costs(
    data=[
        {"date": "2026-11-01T10:00:00+03:00", "actual": 80, "forecast": 100},
        {"date": "2026-11-01T11:00:00+03:00", "actual": 95, "forecast": 90},
    ],
    category="Rüzgar",  # any naming convention, see normalize_kupst_category
    eptr=eptr,
)

## Offline or scenario prices: pass them instead of fetching
calculate_imbalance_prices(
    prices=[{"date": "2026-11-01T00:00:00+03:00", "mcp": 120, "smp": 130,
             "system_direction": -1}],
    kupst_category="wind",
)

    The dated regulation table is get_time_regulation_params_map(); each row names its period (26_01 from 2026-01-01, 26_02 from 2026-11-01).

    calculate_imbalance_prices ¶

    calculate_imbalance_prices(start_date: str | datetime | None = None, end_date: str | datetime | None = None, prices: DataFrame | list[dict] | None = None, eptr: EPTR2 | None = None, kupst_category: str = 'other', include_maintenance_penalty: bool = False, return_df: bool = True, include_calculated: bool = False, **kwargs: float) -> DataFrame | list[dict]

    Hourly imbalance prices, unit costs and every regulation parameter used to calculate them, resolved automatically from each hour's delivery date.

    For each hour the regulation period, price floor and ceiling, V, B, low, high and ceiling margins and the KUPST tolerance, multiplier and floor price are looked up (see get_time_regulation_params_map and contract_to_floor_ceil_prices), so a range spanning regulation changes is priced correctly hour by hour.

    Market prices come from prices if given, otherwise they are fetched from EPİAŞ (mcp-smp-imb) for the range. Where the published imbalance prices are available (always for fetched hours, or 'positiveImbalance' / 'negativeImbalance' in prices) they are used as pos_imb_price and neg_imb_price, and the unit costs follow from them. Otherwise the prices are calculated from MCP, SMP, system direction and the resolved parameters, e.g. for scenarios or offline use.

    Hours without SMP and published prices cannot be priced and are skipped with a warning. EPİAŞ returns every hour of the current day, those after the latest published hour without SMP, so a range ending today returns its published hours only. If no hour has SMP, ValueError is raised. For future hours pass prices with an SMP scenario.

    Start of the range: 'YYYY-MM-DD', ISO datetime, contract code or datetime. Required unless prices is given.

    		 None

    End of the range (inclusive). A date means its last hour.

    		 None

    EPTR2 client for fetching. Created from .env if needed.

    calculate_imbalance_costs ¶

    calculate_imbalance_costs(data: DataFrame | list[dict] | None = None, actual: float | None = None, forecast: float | None = None, date: str | datetime | None = None, category: str = 'other', is_producer: bool = True, prices: DataFrame | list[dict] | None = None, eptr: EPTR2 | None = None, include_maintenance_penalty: bool = False, return_df: bool = True, **kwargs: float) -> DataFrame | list[dict]

    Imbalance and KUPST costs of actual vs forecast quantities, with every price and regulation parameter pulled automatically.

    The hours of data define the range; calculate_imbalance_prices supplies the hourly prices, unit costs and parameters (fetched from EPİAŞ unless prices is given). Published imbalance prices are used where available, calculated ones otherwise (see imb_price_source). KUPST tolerance and multiplier follow each row's category and date.

    data DataFrame | list[dict] | None

    Hourly quantities as a DataFrame or list of dicts with 'date' (or 'contract'), 'actual' and 'forecast' in MWh. Optional per row columns 'category' (or 'source') and 'is_producer' override the function arguments, so a portfolio can mix plant types.

    		 None
    actual float | None

    Actual quantity (MWh) of a single hour instead of data.

    		 None
    forecast float | None

    Forecast quantity (MWh) of that hour.

    		 None
    date str | datetime | None

    Date, datetime or contract of that hour.

    		 None
    category str

    KUPST category or source name in any common convention (e.g. 'wind', 'Rüzgar', 'GES', 'Müstakil depolama'), see normalize_kupst_category.

    		 'other'
    is_producer bool

    Production (True) or consumption (False) unit. KUPST applies to producers only.

    		 True
    prices DataFrame | list[dict] | None

    Hourly prices passed to calculate_imbalance_prices. Fetched from EPİAŞ if None.

    		 None
    eptr EPTR2 | None

    EPTR2 client for fetching.

    		 None
    include_maintenance_penalty bool

    Use the KUPST maintenance multiplier.

    		 False
    return_df bool

    Return a pandas DataFrame if pandas is installed.

    		 True
    **kwargs float

    Parameter overrides passed to calculate_imbalance_prices.

    		 {}

    Returns:

    Type Description
    DataFrame | list[dict]

    One row per input row with the input columns and contract, category,
    DataFrame | list[dict]

    is_producer, mcp, smp, system_direction, pos_imb_price, neg_imb_price,
    DataFrame | list[dict]

    imb_price_source, imb_qty (positive surplus, negative deficit), unit_imb_cost, imb_cost,
    DataFrame | list[dict]

    normalize_kupst_category ¶

    normalize_kupst_category(name: str | None, strict: bool = False) -> str

    Map a source or category name in any common naming convention to one of KUPST_CATEGORIES.

    Matching ignores case, Turkish characters and separators: Turkish characters are folded to ASCII (ı/İ -> i, ş -> s, ğ -> g, ü -> u, ö -> o, ç -> c), so 'Rüzgar', 'ruzgar' and 'RUZGAR' are the same. 'RES', 'wind', 'Güneş', 'GES', 'PV', 'Depolamalı üretim tesisi', 'wind + battery', 'Müstakil depolama', 'BESS', 'İletime bağlı lisanssız', 'Dağıtıma bağlı lisanssız', 'unlicensed', 'HES', 'doğalgaz' all resolve.

    Rules, in order: an exact category name or alias; unlicensed (distribution if a distribution keyword is present, transmission otherwise); battery (plant_w_battery if it is a generation plant with storage, battery if it is standalone storage); wind; solar; other sources.

    Parameters:

    Name Type Description Default
    name str | None

    Source or category name. None gives 'other'.

    		 required
    strict bool

    If True, raise ValueError for names that match no rule instead of returning 'other'.

    		 False

    Returns:

    Name Type Description
    str str

    One of KUPST_CATEGORIES.

    Mapping Utilities¶

    eptr2.mapping¶

    Utilities for API endpoint mapping and discovery.

    from eptr2.mapping import (
    get_path_map,
    alias_to_path,
    get_alias_map,
)

    get_path_map¶

    Returns the complete mapping of API endpoint paths.

    from eptr2.mapping import get_path_map

# Get all path keys
paths = get_path_map(just_call_keys=True)
print(len(paths))  # 234

    alias_to_path¶

    Converts an alias to its canonical path.

    from eptr2.mapping import alias_to_path

path = alias_to_path("ptf")
print(path)  # "mcp"

    get_alias_map¶

    Returns dictionary of all aliases.

    from eptr2.mapping import get_alias_map

aliases = get_alias_map()
# {'ptf': 'mcp', 'smf': 'smp', ...}

    eptr2.mapping.help¶

    Help and documentation utilities.

    from eptr2.mapping.help import get_help_d

    get_help_d¶

    Get documentation for an API endpoint.

    from eptr2.mapping.help import get_help_d

# Get help for specific call
help_info = get_help_d("mcp")
print(help_info['category'])     # "GÖP"
print(help_info['title']['en'])  # "Market Clearing Price"
print(help_info['desc']['en'])   # Description
print(help_info['url'])          # Official docs URL

# Get all help entries
all_help = get_help_d()

    Returns:

    Key Type Description
    category str Market category (GÖP, GİP, etc.)
    title dict Titles in tr and en
    desc dict Descriptions in tr and en
    url str Link to official documentation

    Examples¶

    Finding API Endpoints¶

    from eptr2.mapping import get_path_map, alias_to_path

# List all endpoints
all_endpoints = get_path_map(just_call_keys=True)

# Find price-related endpoints
price_endpoints = [e for e in all_endpoints if 'price' in e.lower()]
print(price_endpoints)

# Check if alias exists
canonical = alias_to_path("ptf")
print(f"'ptf' maps to '{canonical}'")

    Getting API Documentation¶

    from eptr2.mapping.help import get_help_d

# Get documentation for consumption endpoint
help_info = get_help_d("rt-consumption")

print(f"Category: {help_info['category']}")
print(f"Title (TR): {help_info['title']['tr']}")
print(f"Title (EN): {help_info['title']['en']}")
print(f"Description: {help_info['desc']['en']}")

    Working with Contract Symbols¶

    from eptr2.util.time import iso_to_contract

# Convert timestamps to contract symbols
timestamps = [
    "2024-07-29T00:00:00+03:00",
    "2024-07-29T12:00:00+03:00",
    "2024-07-29T23:00:00+03:00",
]

for ts in timestamps:
    contract = iso_to_contract(ts)
    print(f"{ts} -> {contract}")
